- `step(): boolean` owns this caller's sole invocation of `arm.step()`. Capture and validate the current boundary and prepare all active/new casts before advancing. Track expected owner tick from factory creation; an external owner step is a stale-controller error, not permission to skip unqueried travel. A same-boundary animation→physics handoff is allowed. Validate returned epoch/ticks/identities and process all results before publishing any records/events. This operation belongs inside every fixed-step callback, not after the render frame's catch-up loop.
- `cancel()` clears queued/active casts and undrained presentation events, while preserving completed recent diagnostics. It does not destroy or pause the arm. The lab calls it before pause, blur/visibility loss and handoff. Cancelled shots are not misses or damage.
- `read()` returns detached bounded active/queued metadata, recent terminal records and aggregate counters useful to the lab. No mutable owner/native handles or query methods escape. Reading is not event delivery.

Bound this queue to16 too; older events may drop under unattended consumption, but retained identity/diagnostics never redeliver. No anatomy-effect token is implied.
- `destroy()` idempotently closes/clears controller and wrapper, not the arm. Reuse after destruction rejects. An unexpected step/query/post-step processing exception closes the controller and clears all pending/retained output; caller handles owner teardown. Never recreate a batch to retry the consumed tick or publish a partial batch.
